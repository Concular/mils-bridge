# Glossary

The words the rest of the documentation, the console and the code share.
Several of them ("node" above all) carry more than one meaning on purpose;
this page names each meaning once so the other pages do not have to.

## The two systems and this component

| Term        | Meaning                                                                                                                                                                                                                                     | In code                                                                              | In the console                 |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------------ |
| **MILS**    | The metadata tracker this component writes into. JWT bearer auth, braced GUIDs, soft-delete lifecycle. Entities: `Object → Item` (typed by `ItemType`, owned by a MILS `Node`), `ItemLink`, reference data (`Actor`, `Node`, `Country`, …). | `apps/web/mils.yaml`, `apps/api/src/mils/`, `apps/web/src/api/generated/schema.d.ts` | _Data explorer › MILS data_    |
| **Concore** | Concular's building-data platform; the first _source_. Snake_case UUIDs, API key + organisation scoping.                                                                                                                                    | `apps/api/src/concore/`, `apps/web/src/api/generated/concore-schema.d.ts`            | _Data explorer › Concore data_ |
| **BFF**     | The NestJS backend-for-frontend (`apps/api`). Proxies both upstreams server-to-server, owns the mapping store, implements every `/api/*` route the console calls.                                                                           | `apps/api/`                                                                          | The "API origin" in Settings   |
| **Console** | The React web app (`apps/web`), product name **MILS Node**. Talks only to the BFF.                                                                                                                                                          | `apps/web/`                                                                          | Everything you see             |
| **Desktop** | The Electron packaging of BFF + console on `http://localhost:47800`.                                                                                                                                                                        | `apps/desktop/`                                                                      | Same UI, one window            |
| **Bridge**  | Package-name prefix (`@bridge/web`, `@bridge/api`, `@bridge/shared`) from the component's first name, _Concular Bridge_. Only survives in package names and storage keys.                                                                   | `package.json` files                                                                 | —                              |

## Integrations, sources and the target

| Term               | Meaning                                                                                                                                                                                                     | In code                                                                                                            | In the console                      |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ----------------------------------- |
| **Integration**    | One entry of the integration registry: a system this node talks to, with settings, a status probe and a connection test. Exactly five: `mils`, `concore`, `google-drive`, `api-explorer`, `local-elements`. | `INTEGRATION_IDS`, `INTEGRATIONS` in `packages/shared/src/integrations.ts`; `apps/api/src/integrations/providers/` | _Integrations_ page, one card each  |
| **Target**         | The integration entities are registered _into_. Exactly one: MILS.                                                                                                                                          | `IntegrationRole = 'target'`                                                                                       | "Target" badge on the MILS card     |
| **Source**         | An integration whose entities get registered into the target: Concore, Google Drive, API Explorer, Local elements (the console user, with no upstream system).                                              | `IntegrationRole = 'source'`, `SourceIntegrationId`                                                                | "Source" badge                      |
| **Source kind**    | The type of thing a mapping row points at on the source side: the five Concore kinds plus `google-drive-file`, `api-exchange`, `local-file` and `json-value`.                                               | `SOURCE_KINDS` (all), `CONCORE_KINDS` (Concore-only code) in `packages/shared/src/mapping.ts`                      | Kind column on _Mappings_           |
| **API (Explorer)** | A user-imported OpenAPI document with a base URL and a credential, explored with the Scalar client through a per-API proxy. The one integration with user-created instances.                                | `ApiIntegration` model, `apps/api/src/api-explorer/`                                                               | _API Explorer_                      |
| **Exchange**       | One recorded request/response pair through an API's proxy. Registering an exchange makes it an element.                                                                                                     | `ApiExchange` model                                                                                                | _Requests_ tab of an API            |
| **Stored file**    | The local, content-addressed copy of a registered file — from Google Drive, or uploaded from the console. Served from disk, never re-fetched from the source.                                               | `StoredFile` model, `apps/api/src/file-store/`                                                                     | Google Drive browser, _Files_ links |

## Mappings, registration, elements

| Term                 | Meaning                                                                                                                                                                                                                        | In code                                                                                                                             | In the console               |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------- | ---------------------------- |
| **Mapping**          | The durable cross-reference between one source entity (`kind` + `id`) and one MILS resource (`Item` or `Object` + id). One-to-one in both directions. Lifecycle `PENDING → REGISTERED / FAILED`, then `ARCHIVED` and back.     | `ResourceMapping` model; `MAPPING_STATUSES`; `apps/api/src/mapping/`                                                                | _Mappings_ list              |
| **Registration**     | The act of creating a MILS Item for a source entity and persisting the mapping, the payload and a log row. Also the name of the `/api/integration/registrations` write.                                                        | `apps/api/src/registration/` (Concore), `google-drive/`, `api-explorer/`, `local-elements/` (each has its own registration service) | "Register" actions           |
| **Element**          | A registered thing seen from the access-control side: a `REGISTERED` mapping with its MILS item, the unit that nodes read and that access rules attach to.                                                                     | `ElementAccess`, `ElementAccessRule`; `ElementAccessGuard` / `ElementRefGuard` in `apps/api/src/access/`                            | _Access → Elements_          |
| **Payload**          | The bytes the mils-internal `ItemData` endpoint serves for a MILS item: the Concore snapshot, the `StoredFileDto` descriptor of a stored file, the exchange body, or a typed JSON value. Written by registration, or manually. | `MilsItemPayload` model, `apps/api/src/item-payload/`, `ITEM_PAYLOAD_MAX_BYTES`                                                     | _Item payloads_              |
| **Snapshot**         | The Concore entity as fetched at registration time, stored on the mapping and reused as the payload.                                                                                                                           | `ResourceMapping.concoreSnapshot`                                                                                                   | JSON disclosure on a mapping |
| **Registration log** | The append-only domain trail of registration actions (`REGISTER`, `UPDATE`, `ARCHIVE`, `REACTIVATE`; `SUCCESS` / `FAILED`).                                                                                                    | `RegistrationLog` model, `REGISTRATION_ACTIONS`                                                                                     | Activity feed                |

## Who calls the BFF

| Term             | Meaning                                                                                                                                                                                                                                                                                                                                                                                               | In code                                                                                                  | In the console                                                       |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| **Console user** | A person signed in to the console. Roles `ADMIN` and `MEMBER`; the first user is created on `/setup`.                                                                                                                                                                                                                                                                                                 | `User`, `Session` models; `apps/api/src/auth/`, `apps/api/src/users/`                                    | _Users_ (admins), _Account_                                          |
| **Session**      | The HTTP-only cookie a console user holds. The guard for every console-only route.                                                                                                                                                                                                                                                                                                                    | `AuthGuard`, `session-cookie.ts`                                                                         | Sign in / sign out                                                   |
| **Actor**        | A MILS `Actor`: an external system with a certificate. The BFF keeps a registry of them and verifies their JWTs on the actor API.                                                                                                                                                                                                                                                                     | `ActorRegistration` model, `apps/api/src/actor-registry/`, `ActorAuthGuard`, `ActorTokenVerifierService` | _Actors_ (MILS reference list)                                       |
| **Node**         | Three meanings, deliberately: (1) **this component** — the product name _MILS Node_; (2) a **MILS `Node`** — the reference entity that owns Items (`/nodes` list); (3) in **Access**, a _node_ is an **actor** that fetches registered data through the bridge — the console calls actors "nodes" on the Access pages because that is how the operator thinks of them. Pages say which one they mean. | (2) `GET /api/mils/Nodes`; (3) `ActorAccessDefault`, `apps/web/src/features/access/nodes-tab.tsx`        | (1) sidebar brand; (2) _Data explorer → Nodes_; (3) _Access → Nodes_ |
| **Principal**    | The identity a request carries: a console user, an actor, or none.                                                                                                                                                                                                                                                                                                                                    | `RequestMetric.principalType`                                                                            | —                                                                    |
| **Caller**       | A display heuristic on request metrics: `console` when the request had a session cookie or an allow-listed `Origin`/`Referer`, else `external`. Not an authorization boundary; the only way to tell the console's own reads from a node's on the unauthenticated surfaces.                                                                                                                            | `classifyCaller` in `apps/api/src/metrics/caller.ts`                                                     | _Access → Statistics_ (external only)                                |
| **Surface**      | Which route family a request hit (`mils`, `concore`, `integration`, `mils-internal`, …), stored on every request metric.                                                                                                                                                                                                                                                                              | `classifySurface` in `apps/api/src/metrics/surface.ts`                                                   | Statistics breakdown                                                 |

## Access control

| Term                 | Meaning                                                                                                   | In code                                                       | In the console           |
| -------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------ |
| **Policy**           | The single global default: what a node may read when nothing more specific says otherwise.                | `AccessPolicy` (one row)                                      | _Access → Policy_        |
| **Node default**     | Per-actor default, overriding the policy for that actor.                                                  | `ActorAccessDefault`                                          | _Access → Nodes_         |
| **Element mode**     | Per-element setting: inherit, allow all, block all, or use the element's rules.                           | `ElementAccess`                                               | _Access → Elements_      |
| **Rule**             | Per-element, per-actor allow/block.                                                                       | `ElementAccessRule`                                           | Element drawer           |
| **Inherit**          | "Absent row means INHERIT": every level falls through to the next when it has no row.                     | `resolveAccess` in `packages/shared/src/access-resolution.ts` | "Inherited" badges       |
| **Enforcement mode** | How far the BFF acts on a decision: `off`, `shadow` (record only, default), `enforce` (block with `403`). | `ACCESS_ENFORCEMENT`, `ElementAccessGuard`                    | Mode shown on _Policy_   |
| **Decision**         | The resolved outcome for one (actor, element) pair: `ALLOW` or `BLOCK`, plus the level that decided it.   | `resolveAccess` result                                        | "Effective access" panel |

## Cross-cutting

| Term               | Meaning                                                                                                                                                             | In code                                  | In the console                 |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ------------------------------ |
| **Settings**       | The single persisted `IntegrationSettings` row: runtime MILS base URL + signing key, Concore base URL + API key + org, Google OAuth app. Overrides env.             | `apps/api/src/settings/`                 | Panels on `/integrations/<id>` |
| **Audit event**    | A generic append-only "who changed what" row (settings, access, actor toggles, mapping archive/reactivate).                                                         | `AuditEvent`, `AuditService.record()`    | _Audit_, activity feed         |
| **Request metric** | One row per counted request: surface, route pattern, status, duration, principal type, caller, element. Pruned at 31 days.                                          | `RequestMetric`, `apps/api/src/metrics/` | Statistics, dashboard headline |
| **mils-internal**  | The `apps/web/mils-internal.yaml` API, implemented locally by the BFF from its own store and deliberately unauthenticated: `ItemData`, `ItemFile`, object accesses. | `apps/api/src/mils-internal/`            | —                              |
